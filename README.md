# Agent-Builder-UI
## Agent Builder UX Explorer

Interactive demos of 8 UX approaches for the SNS Square Agent Builder, plus a combined recommendation (Option 9).

Vanilla HTML/CSS/JS, no build step. Some demos load scripts inside an iframe, so serve the folder instead of opening files directly:

```
python -m http.server 5173
```

Then open http://localhost:5173/index.html
